Core concept

A shared password lands you on an MFA-protected account. Messaging allows HTML, so XSS runs as the victim and calls /api/mfa/disable. Privileged report editor fetches file:// URLs into base64 image sources — steal SSH keys offline.

2. Stored XSS disables MFA

Why: browser executes XSS with tommy’s cookies → same-site API disables MFA without UI confirmation.

Beyond Root

  • Rate-limit + lockout on login; never rely on MFA alone after password spray.
  • Sanitize message HTML; CSP; block inline handlers.
  • Rich editors: allow only http(s) image schemes; never fetch file://.
  • SSH keys not readable by web process; use short-lived certs.
